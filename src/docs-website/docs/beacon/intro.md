# Overview

Beacon is AirQo's device health monitoring platform. Where [Vertex](/vertex/intro) is where you register and deploy your monitors, Beacon is where you find out whether they're actually working. It can help you:

- **See your fleet's health at a glance:** Track online rate, uptime trends, and incidents across every monitor you operate.
- **Diagnose a single monitor:** Open any device to inspect its performance history, configuration, metadata, and files.
- **Compare across manufacturers:** Filter the whole dashboard by sensor manufacturer or by cohort, so a mixed fleet can be assessed fairly.
- **Plan field maintenance:** Use the maintenance map to find which monitors need a visit, and plan a route between them.
- **Export evidence:** Generate PDF device health reports for funders, partners, and internal review.

Beacon reads the same device registry as Vertex, using the same AirQo account. Anything you register in Vertex — AirQo hardware or a third-party monitor from any manufacturer — appears in Beacon automatically. There's nothing to set up in Beacon itself.
