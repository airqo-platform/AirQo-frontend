# Ask AirQo

Ask AirQo is a beta assistant inside Nexus. It provides a guided starting point for questions about air quality, saved places, comparisons, data visualization, data export, and rankings.

The feature is optional. If it is not enabled for your environment, the Ask AirQo entry point is not shown.

## Open Ask AirQo

- From **Home**, select the **Ask AirQo** card.
- On supported feature pages, select the **Ask AirQo** action in the page header.

The assistant can use the current page context to suggest relevant actions, such as opening a comparison, creating a trend chart, uploading a dataset, exporting data, or viewing rankings.

## Use the assistant

1. Open Ask AirQo.
2. Choose a suggested prompt or enter a question in **Ask about air quality...**.
3. Read the response and follow any action link it provides.
4. Select **Clear chat** to start a new conversation.

## Important limitations

:::warning Beta guidance only
Ask AirQo is guidance, not a replacement for the underlying data, the Nexus interface, or professional health and research advice. Verify important values and decisions in the relevant Nexus page or in the source data.
:::

- The chat is not saved to your account.
- Ask AirQo does not change account settings or data.
- Responses may be incomplete or unavailable when the supporting data is not loaded.
- For research, policy, or health decisions, use the underlying measurements and appropriate professional guidance.
